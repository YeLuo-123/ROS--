# 当前状态中心

## 1. 目录职责

提供项目当前事实、近期任务、路线图和问题入口。

## 2. AI读取规则

每次开始项目任务时优先读取`CURRENT_STATUS.md`。

## 3. 文件规范

- `CURRENT_STATUS.md`只记录当前事实。
- `TASK_BOARD.md`记录待办、进行中和完成项。
- `ROADMAP.md`记录阶段路线。
- `ISSUES.md`记录尚未解决的问题。

## 4. 禁止事项

不得把历史过程堆入当前状态；历史原因放入`40_memory/`或`05_CHANGELOG.md`。

## 5. 维护规则

每次形成实质性成果后更新。
