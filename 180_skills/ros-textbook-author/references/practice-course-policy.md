# 生产实习与综合课程设计双轨规范

## 课程定位

### 生产实习

目标是让学生熟悉机器人工程环境、设备、部署和工作流程，形成安全操作、规范记录、系统调试和岗位协作能力。任务以指导性、规范性和重复验证为主。

本项目课程参数：连续1周、每天8学时、校内教室实施，面向国际教育学院机械工程及自动化专业大三学生，每届约90人，每组8人、配置1名指导教师，无企业现场和企业导师，以设备认识和部署为主，允许修改底层程序。最终提交实习报告、算法成果和录屏文件。

### 综合课程设计

目标是让学生围绕开放需求完成方案论证、系统设计、多模块集成、测试验收、技术报告和答辩。任务以设计性、综合性和方案选择为主。

本项目课程参数：面向机械工程及自动化专业大四学生，每届约90人，10周、2名指导教师，每组5至6人、每组一个题目；教师提供题库，设置开题、中期检查和最终验收，要求现场答辩、实物作品、仿真内容和课程设计报告。课程不强制使用ROS或ROS2。

## 共享案例的双轨改编

同一个项目可以共享任务背景、硬件平台、基础数据和最低验收指标，但必须提供两套教学任务。

| 项目 | 生产实习路线 | 综合课程设计路线 |
|---|---|---|
| 输入 | 操作规程、已有工程或半成品 | 需求书、约束、接口资源 |
| 学生责任 | 部署、操作、调试、记录 | 分析、设计、实现、集成、测试 |
| 教师作用 | 示范、检查和过程管理 | 需求评审、方案评审和验收 |
| 主要成果 | 日志、工单、调试记录、实习报告、算法成果和录屏文件 | 方案、代码、系统、测试报告和答辩 |
| 主要评价 | 安全、规范、执行和排错 | 设计、集成、鲁棒性和工程质量 |

## 生产实习必备内容

- 实习目标、岗位或工程情境。
- 人员、设备和场地安全要求。
- 上电、接线、网络、权限和环境检查清单。
- 软件部署、参数备份、启动和关闭流程。
- 规定的观察、标定、测试和故障诊断任务。
- 实习日志、故障工单、变更记录和交接记录。
- 每日或阶段检查点。
- 现场操作、过程记录和总结答辩评价。

## 综合课程设计必备内容

- 任务书、功能需求、性能指标、约束和交付物。
- 选题和可行性论证。
- 至少两种候选方案及选择依据。
- 节点架构、接口、TF树、数据流和团队分工。
- 需求评审、方案评审、中期检查和最终验收。
- 测试方案、重复实验、失败边界和鲁棒性分析。
- 代码仓库、版本环境、课程设计报告和现场答辩。
- 基础要求、提高要求和有证据的创新任务。

## 案例组织建议

案例按能力和系统类型组织，不按赛事名称组织：

1. 基础系统：数据记录、状态监测、自动绘图和多节点协作。
2. 移动机器人：建图、导航、巡检、配送和搬运。
3. 机械臂：运动规划、视觉抓取、分拣和码垛。
4. 视觉与AI：检测、定位、视觉导航和视觉伺服。
5. 综合系统：移动操作、多机器人、智能巡检和竞赛改编。

竞赛名称、届次、成绩和规则放入案例来源与拓展部分；规则变化不得破坏案例的核心教学任务。

## 开课参数

在确定第三册最终目录和案例数量前，记录两门课程各自的：

- 学分、总学时和连续/分散安排；
- 开课学期和学生先修课程；
- 学生人数、分组规模和指导教师数量；
- 可用机器人、传感器、机械臂、计算机和场地；
- ROS主版本、仿真环境和实物比例；
- 课程目标、毕业要求指标点和学校考核规定。

已确认硬件基础为20台ROS2移动机器人小车及双目相机、激光雷达、IMU等，学生自带电脑。设备型号、电脑最低配置、网络权限和并发使用安排仍需补充。

没有这些参数时，只输出建议方案，并明确尚未完成课程适配验证。
