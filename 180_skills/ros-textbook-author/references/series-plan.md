# 《机器人操作系统与智能机器人开发》系列教材总体规划

## 系列总目标

面向已具备基本计算机操作能力的本科生，以“理解系统—掌握技术—完成工程”为递进主线，培养学生分析、搭建、调试和评价机器人软件系统的能力。全系列以中文讲解为主，规范呈现英文术语、命令、接口和代码标识符。

“智能机器人开发”采用“感知—决策—执行—反馈”闭环定义：利用ROS组织机器人软件，以传感器和系统状态为输入，通过规则、算法或模型形成决策，驱动机器人执行任务，并依据反馈持续修正。智能不等同于深度学习，也包括自主定位、规划、反馈控制、故障恢复、人机交互和多机器人协同。

典型读者为机器人工程、智能制造、机械电子、人工智能和计算机等专业的大三本科生，也可供相关研究生使用。默认读者学过机器人学、自动控制、计算机网络和Python，但不默认具备Linux基础。

## 第一册：基础篇——ROS核心原理与程序设计

### 定位

服务2026版2学分、32理论学时的《机器人操作系统（双语）》；不单独适配老版本合并课程。

建立ROS系统思维，使学生理解机器人程序为什么需要被拆分、组织和通信，并能完成一个可观察、可调试的小型ROS系统。通过turtlesim把订阅状态、形成决策、发布指令和反馈修正组织成最小智能机器人软件闭环。

### 建议内容

- ROS 所需的 Linux/Ubuntu 基础：终端、路径、权限、进程、环境变量、软件安装和 Git。
- ROS 的设计目标、节点与计算图。
- Topic、Message、Service、Action 和 Parameter。
- 工作空间、Package、构建系统和 Launch。
- 日志、命令行工具、数据记录和固定排错流程。
- ROS1 与 ROS2 的共同概念、实现对照和迁移提示。
- 以 turtlesim 为主线的基础综合项目。
- 贯穿总案例使用“TurtleMission单乌龟自主任务系统”，按TurtleGoal、TurtleGuard、TurtlePainter和TurtleMission四个版本在同一工程上递进开发，具体规范见`references/volume-1-turtlesim-case.md`。
- 章节安排固定为“前5章基础＋后4章阶段案例＋第10章迁移测试与总结”：第6至9章依次完成TurtleGoal、TurtleGuard、TurtlePainter和TurtleMission，不把完整案例机械拆散到前5章，也不在第10章新增案例。
- 以“状态获取—规则决策—运动执行—结果反馈”解释Topic、Service、Action、Parameter和调试工具在智能机器人开发中的作用。
- 期末项目按自主任务系统设计，包含目标输入、状态获取、控制决策、任务状态、异常处理和运行评价。
- 编程基础、面向对象、CMake、XML、YAML和JSON放入附录或按需前置。

### 边界

- 只介绍TF的存在、用途和最小观察方法；TF深入应用、状态机、欧拉角、四元数、旋转矩阵、外参标定和TF故障专题放入第二册。多乌龟不再作为后续教材主线，多机器人追踪与编队转入第三册竞赛或综合项目案例。
- 只用 RViz/Gazebo 支撑基础观察，不展开复杂机器人仿真。
- 不展开 SLAM、导航、MoveIt、视觉部署和竞赛系统集成。

## 第二册：应用篇——建模、感知、规划与控制

### 定位

服务2026版0.5学分、16实践学时的《机器人操作系统实践》，并可独立使用；不单独适配老版本合并课程。

围绕典型机器人技术栈，训练学生把建模、仿真、坐标变换、感知、定位、规划、决策和控制组织成可运行系统。本册是“智能机器人开发”的核心功能册。

### 建议内容

- URDF、Xacro、法奥意威FR5统一教学机器人模型和传感器模型。
- RViz、Gazebo、仿真与实物接口。
- TF/TF2、欧拉角、四元数、旋转矩阵、齐次变换、传感器外参标定、TF树设计和故障诊断。
- 底盘、编码器、IMU、激光雷达、深度相机及底层通信。
- 里程计、SLAM、定位、自主导航、代价地图和规划。
- 法奥意威FR5机械臂建模、MoveIt、运动规划、碰撞检测和抓取。
- ROS 图像消息、相机标定、OpenCV、YOLO 和三维定位。
- 从仿真到实物的系统集成与工程规范。
- 状态机作为行为树的对照基础，重点讲Nav2行为树驱动的任务决策、异常检测与故障恢复。
- 使用麦克纳姆轮ROS2全向移动机器人作为主要实物平台，不采用阿克曼底盘；围绕STM32、IMU、激光雷达和深度相机构建实操任务。

### 边界

- 不重复第一册的完整通信机制，只在应用中调用并复习。
- 单模块实验可在本册出现；多模块集成、工程交付、生产实习任务、综合课程设计和项目验收放入第三册。

## 第三册：项目篇——生产实习、课程设计与竞赛案例

### 定位

面向生产实习和综合课程设计，通过可复现的机器人项目案例，训练学生完成需求分析、系统设计、软硬件集成、部署调试、测试验收、技术报告和项目答辩。每个案例须将感知、决策、执行和反馈落实到系统架构、接口、算法、测试与验收证据中。竞赛项目是高质量案例来源之一，而不是全书唯一组织主线。

### 建议内容

- 项目开发基础：需求分析、任务分解、ROS架构、接口设计、Git协作、计划、风险和验收。
- 生产实习：安全规范、设备认识、环境部署、软硬件调试、故障记录、实习日志和交接。
- 综合课程设计：选题、任务书、可行性论证、方案评审、分阶段实现、系统联调、报告和答辩。
- 分层项目案例：移动机器人、机械臂、视觉、巡检、搬运、多机器人和综合智能系统。
- 来自企业、实验室、教学、科研和学科竞赛的案例重构与复现。
- 过程检查、现场操作、代码审查、故障诊断、系统验收、性能评价和成果归档。
- 全书设置12个项目案例：基础、移动机器人、机械臂、视觉AI、综合系统和竞赛来源各2个，每类先简单后复杂，复现目标为R2至R3。

### 双轨使用规则

- 同一案例可以服务两门课，但必须分别给出“生产实习路线”和“综合课程设计路线”。
- 生产实习路线提供明确流程或半成品工程，强调安全、规范、部署、观察、调试和记录。
- 综合课程设计路线主要提供需求、约束和验收指标，要求学生完成方案选择、系统设计、集成、测试与答辩。
- 两门课程分别设置提交物、阶段检查点和评分量规，不用一套标准简单复用。

### 案例准入条件

- 来源清楚，知识产权和引用边界明确。
- 能获得足够信息重建系统架构。
- 能定义环境、输入、输出、指标和验收证据。
- 至少明确体现感知、决策、执行、反馈中的一个智能能力，并说明它与其他环节的接口；综合案例应形成完整闭环。
- 至少具备仿真复现路径；实物验证状态必须明确标注。
- 能说明适用课程、建议学时、人员规模、设备条件和教师准备工作。
- 能分别设计生产实习和综合课程设计的使用方式，或明确只适用于其中一门课。

## 跨册规则

1. 一个主题只在一册中完整展开，其他分册只提供必要回顾和交叉引用。
2. 第一册回答“ROS如何组织智能机器人程序”，第二册回答“如何开发智能机器人功能”，第三册回答“如何在实习和课程设计中交付并评价智能机器人系统”。
3. 教学主线从可观察现象出发，经由概念、实现、调试走向反思，不以命令罗列代替教学。
4. 所有目录均为可修订结构；在读者对象、总学时和主版本确定前，标注为“建议目录”。
5. 课程实施说明只采用2026版“2学分理论课＋0.5学分实践课”的拆分结构；任课教师可根据实际开课版本自行组合和删减，但不将临时调整写入教材基线。
