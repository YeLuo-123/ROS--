# 项目长期记忆

- 用户更重视材料是否真正更新、代码是否实际验证，而不是仅有规划性描述。
- 第一册案例必须是同一TurtleMission代码基线的四个递进版本，不能写成四个无关案例。
- Windows工作区用于写作和静态审查；ROS运行结论必须明确记录环境和证据。
- 参考材料不是原创内容，使用时必须改写、核实、引用并检查许可。
- 已批准结构和术语在后续任务中持续有效，除非用户明确修改。
- 教材LaTeX初稿统一放入对应稿件目录下的`draft/`子目录，文件名使用详细章节编号加英文短横线slug，例如`06-02-mecanum-wheel-kinematics.tex`；后续所有`.tex`均按项目`ros-textbook-author` Skill补齐定位、目标、先修、术语、教学递进、验证状态和引用边界。
