# 验证中心

## 1. 目录职责

保存静态审查、ROS构建、仿真运行、故障注入和版本复现记录。

## 2. AI读取规则

准备声明“可运行”“已验证”或发布教材代码前必须读取。

## 3. 当前结论

- 4个ROS 2 Demo已做Python/XML/YAML等静态检查。
- 当前Windows工作区没有ROS 2 Humble运行环境。
- Ubuntu 22.04 + ROS 2 Humble端到端验证尚未完成。

## 4. 记录要求

每次验证记录操作系统、ROS版本、提交版本、依赖、命令、预期、实际证据、日期和验证范围。

## 5. 禁止事项

不得虚构终端输出或运行指标；静态检查不等于运行验证。
